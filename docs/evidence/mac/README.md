# Подтверждения пользователя: macOS
- terminal_fault_mac_original.png — полный неизменённый скриншот Терминала. Видны первоначальная ошибка рабочей папки, успешные запросы и FAULT.
- ../../fault_result_mac.png — обрезка этого скриншота для читабельности результата FAULT. Значения и текст изображения не редактировались.
- ../../flow_editor_mac.png — предоставленный ранее скриншот редактора Node-RED на Mac. Панель Debug на нём пустая; снимок подтверждает открытый flow, но сам по себе не результат загрузки.
- terminal_session_mac.txt — текст сессии из сообщения пользователя. Последний SELECT показывает THRESHOLD после возврата к основному логу. На скриншоте этой последней команды нет; восстановление подтверждено именно присланным текстом.
- Проверка подтверждает программную загрузку искусственного FAULT и последующий возврат к исходному логу на Mac. Не подтверждает NORMAL из Wokwi, реальный отказ датчика, Windows-запуск или верность всех соединений EasyEDA.
- variant.db с компьютера пользователя не присылалась. В архиве оставлена прежняя проверенная база с основным логом; скриншот не выдаётся за импорт файла базы с Mac.
