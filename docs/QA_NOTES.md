# Границы проверки
Проверено: реальный Node-RED на Linux; узлы чтения/записи, inject и watch, парсер, транзакционная загрузка SQLite; ошибочный формат; отсутствие дублей; FAULT; хостовая C++-логика исходного скетча с заглушками.
Exec во время проверки использовал временный адаптер команды sqlite3 к библиотеке SQLite из Python. Это не проверка sqlite3.exe и не проверка Windows. Адаптер в архив не включён.
Скриншот flow_editor_linux.png получен из настоящего локального редактора Node-RED. flow_overview.png — нарисованная иллюстрация конфигурации.
log_test.txt и log_fault.txt — искусственные тестовые входы. log.txt и sketch.ino — исходные материалы пользователя.
После всех испытаний в variant.db и load.sql восстановлен исходный log.txt. Git-история не создавалась; init-git.bat записывает текущие коммиты после запуска пользователем.
Wokwi, исходный EasyEDA и Windows-портативная среда не запускались. Персональные поля записки не заполнялись выдуманными данными.
Реле: справочник https://docs.wokwi.com/parts/wokwi-relay-module содержит таблицу атрибутов и описание поведения. Перед сдачей проверять контакты COM/NO/NC в симуляторе, а не только цвет индикатора; активный LOW принят из присланного скетча.

Дополнение: пользователь предоставил подтверждения на macOS — FAULT и последующий THRESHOLD. Это отдельные пользовательские материалы, не агентский запуск Mac. База с Mac не загружалась. См. evidence/mac/README.md.
