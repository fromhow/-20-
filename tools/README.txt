Бинарные программы не включены. Возьмите tools у преподавателя.
Ожидаются: tools/git/cmd/git.exe; tools/node/node.exe;
tools/sqlite/sqlite3.exe; tools/nodered/node_modules/node-red/red.js.
Допускается расположение tools в %USERPROFILE%\tools.
Node-RED: npm install --prefix "%USERPROFILE%\tools\nodered" node-red
Официальные источники: https://git-scm.com/ https://nodejs.org/ https://sqlite.org/download.html
